## CONTROLS

```
ARROWS / WASD    steer
M                mute
ENTER / CLICK    restart
```

## RULES

- walls are lava. ribs are lava-er
- eat food to grow
- gold food (every 5th) = 5× score
- eating fast = combo multiplier — stacking into the stratosphere
- score one point. then another. until the machine loves you back

## RUN IT

No build. No install. No `npm i`.

```sh
git clone https://github.com/gabarsolon/snake-game.git
cd snake-game
open index.html          # macOS
```

or double-click `index.html` like it's 1998.

Audio unlocks on your first keypress (browser autoplay policy — same rule as love).

## TIP

Grab gold. Chain combos. Trip the tempo up. The music knows when you're winning.
